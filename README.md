# bilibili-audio-quality

B 站网页播放器的音质脚本：在原生「清晰度」菜单里加一行音质入口，想听哪档点哪档。

| 脚本 | 版本 | 作用 | 大小 |
|---|---|---|---|
| [bilibili-audio-quality.user.js](https://stevenamt.github.io/bilibili-audio-quality/bilibili-audio-quality.user.js) | 2.0.3 | 清晰度菜单里的音质切换 | ~16 KB |

## 安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)
2. 点上面的脚本链接，Tampermonkey 弹出安装面板，点「安装」
3. 之后照 `@updateURL` 自动检查更新

## 用法

打开视频页（`www.bilibili.com/video/BV…`），点播放器右下角的「清晰度」。菜单最下面会多一行：

```
音质 · 极高 ▸
```

点它切到音质视图，里面是：

- 自动（不干预，播放器自己挑）
- 最高可用（取能解的最高档）
- 平台实际下发的每一档，后面跟实测码率，例如「极高 · 193 kbps」
- 浏览器解不了的档位显示「（无法解码）」，半透明且点不动

入口行显示的是你选的那一档。

## 换档行为

选任何档位都重载页面，首屏直接取目标流，约 3 秒。重载前记住播放位置，2 分钟内有效，回来自动 seek 回原处。

## 档位

| 音轨 id | 平台文案 | 备注 |
|---|---|---|
| 30216 | 标准 | |
| 30232 | 较高 | 未登录一般最高到这档 |
| 30280 | 极高 | 登录后常见 |
| 30250 | 杜比全景声 | 需大会员 + 片源支持 |
| 30251 | Hi-Res 无损 | 需大会员 + 片源支持，48 kHz / 24 bit |

平台不下发的档位不会显示。脚本不破解会员，只用当前账号已经下发的档位。

## 已知限制

- 换档要重载页面，不是无缝切换
- Linux 上的 Chrome 解不了杜比 E-AC-3，杜比档会标「无法解码」
- 只在 `www.bilibili.com/video` 注入：番剧、稍后再看、收藏夹、课程的播放页没有音质菜单

## 原理

B 站没有「指定音质」的参数，`playurl` 的响应一次带多路音频。这些音轨全部被交给播放器的 dashjs 引擎，每一路都是一个可选档——**播放器本来就有全部档位，只是界面不给你选**。

脚本在播放器读到响应之前，按存档只留目标那一路：`dash.audio` 缩成单个对象，`dash.flac` / `dash.dolby` 清空。播放器没得挑，只能播它。

音轨三处来源：`dash.audio`（数组）、`dash.flac`（单个对象）、`dash.dolby`（数组）。三处都先收进完整档位表，菜单才能把每一档列出来；选中的是 flac 或杜比时，把那一档的对象直接放进 `dash.audio`。

拦截三条路：首屏内联 `__playinfo__`、`fetch`、`XMLHttpRequest`。`dash` 对象在投稿页是 `data.dash`，番剧页是 `result.dash`，有的接口在 `result.video_info.dash`。

界面全部并进原生菜单的同一条 `li` 结构，位置、样式、hover、全屏重定位、点外部关闭都交给播放器，脚本不自绘按钮、不自绘浮层。
