# bilibili-audio-quality

B 站网页播放器的音质脚本：在原生「清晰度」菜单里加一行音质入口，想听哪档点哪档。

| 脚本 | 版本 | 作用 | 大小 |
|---|---|---|---|
| [bilibili-audio-quality.user.js](https://stevenamt.github.io/bilibili-audio-quality/bilibili-audio-quality.user.js) | 1.6.0 | 清晰度菜单里的音质切换 | ~17 KB |

## 安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)
2. 点上面的脚本链接，Tampermonkey 弹出安装面板，点「安装」
3. 之后照 `@updateURL` 自动检查更新

## 用法

打开任意视频，点播放器右下角的「清晰度」。菜单最下面会多一行：

```
音质 · 极高 ▸
```

点它切到音质视图，里面是：

- 自动（不干预，播放器自己挑）
- 最高可用（取浏览器能解的最后一档）
- 平台实际下发的每一档，后面跟实测码率，例如「极高 · 192 kbps」
- 浏览器解不了的档位显示「（无法解码）」，半透明且点不动

选完会重载页面，播放位置自动恢复到换档前（2 分钟内的记录有效）。入口行显示的是当前实际在跑的那一档，不是你以为的那一档——选「自动」时播放器可能自己降档。

## 档位

| 音轨 id | 平台文案 | 备注 |
|---|---|---|
| 30216 | 标准 | |
| 30232 | 较高 | 未登录一般最高到这档 |
| 30280 | 极高 | 登录后常见 |
| 30250 | 杜比全景声 | 需大会员 + 片源支持 |
| 30251 | Hi-Res 无损 | 需大会员 + 片源支持 |

平台不下发的档位不会显示。脚本不破解会员，只用当前账号已经下发的档位。

## 已知限制

- 只处理投稿页 / 普通视频页的 `data.dash`；番剧页的 `result.dash`、`result.video_info.dash` 不生效
- 换档要重载页面，不是无缝切换
- Linux 上的 Chrome 解不了杜比 E-AC-3，杜比档会标「无法解码」

## 原理

B 站没有「指定音质」的参数，`playurl` 的响应一次带多路音频，播放器自己挑一路。脚本在播放器读到响应之前把 `dash.audio` 只留目标那一路，并把 `dash.dolby` / `dash.flac` 清空，播放器就没得挑。

音轨三处来源：`dash.audio`（数组）、`dash.flac`（单个对象）、`dash.dolby`（数组）。

拦截三条路：首屏内联 `__playinfo__`、`fetch`、`XMLHttpRequest`。

界面全部并进原生菜单的同一条 `li` 结构，位置、样式、hover、全屏重定位、点外部关闭都交给播放器，脚本不自绘按钮和浮层。
